Provides assisted upgrading of Maven, Gradle, GitHub Actions, NPM, and Antora dependencies, plus Maven and Gradle wrapper properties, in your IDE. The plugin highlights dependency declarations for newer versions and offers a controlled path to apply updates without replacing your own judgment about when to upgrade.

The support includes:
  • Scanning of pom.xml (Maven), build.gradle(.kts), gradle.properties, settings.gradle(.kts), gradle/libs.versions.toml (Gradle), action.yaml and workflows (GitHub Action), package.json (NPM), antora-playbook.yml (Antora)
  • Determining version update candidates against remote repositories
  • Selection of dependencies and plugins to update
  • Supports Maven Central, custom Maven repositories, npmjs, and GitHub as release metadata sources
  • Shows Package Checker vulnerability information for Maven and npm packages when that IDE service is available

First Steps

  • Open a build file in the editor.
  • Use the intention action (light bulb) on a dependency or plugin version to check for updates.
  • Or use the menu action Tools | Dependency Assistant | Update Dependencies….
