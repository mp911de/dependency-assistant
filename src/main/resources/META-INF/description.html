Provides assisted upgrading of Maven, Gradle, GitHub Actions, NPM, and Antora dependencies, plus Maven and Gradle wrapper properties, in your IDE. The plugin highlights dependency declarations for newer versions and offers a controlled path to apply updates without replacing your own judgment about when to upgrade.

The support includes:
  • Scanning of build files:
    • Maven: pom.xml, .mvn/extensions.xml, and maven-wrapper.properties
    • Gradle: build.gradle(.kts), settings.gradle(.kts), gradle.properties, gradle-wrapper.properties, and *.versions.toml version catalogs
    • GitHub Actions: .github/workflows/*.yml and action.yml
    • NPM: package.json
    • Antora: antora-playbook.yml
  • Determining upgrade candidates against Maven Central and custom Maven repositories (including settings.xml credentials and mirrors), the Gradle Plugin Portal, Gradle distributions, npmjs, GitHub releases, and Git tags
  • Completion, quick documentation, and gutter markers for versions in the editor
  • Interactive upgrade review: pick target versions per dependency, with patch, minor, major, preview, and release upgrade strategies
  • Upgrade Plan tool window to stage upgrades, preview changes, create GitHub tickets, and apply upgrades as a batch or one commit per upgrade
  • Dependency rules via dependencyfile.json to pin artifacts to generations and restrict upgrade strategies per branch
  • Inspections for version and declaration drift, dependency rule violations, unpinned GitHub Actions, and wrapper URL issues; intentions to insert wrapper SHA-256 checksums, open release notes, and report issues
  • Package Checker vulnerability information for Maven and npm packages when that IDE service is available, including safe-version remediation

First Steps

  • Open a build file in the editor.
  • Use the intention action (light bulb) on a dependency or plugin version and choose Upgrade dependencies….
  • Or use the menu action Tools | Dependency Assistant | Upgrade dependencies….

Requires IntelliJ IDEA 2025.2 or newer and installs on any IntelliJ-based IDE. Ecosystem support activates with the corresponding IDE plugins.
