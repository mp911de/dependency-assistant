This built-in template is used each time Dependency Assistant commits an applied Upgrade Plan item.

This built-in template is editable. Along with plain text and Velocity directives, you can also use the predefined variables listed below. They are expanded into the corresponding values. Runs of blank lines collapse into a single blank line and surrounding whitespace is removed, so variables that expand to an empty string leave no trace.

${DEPENDENCY} The dependency or upgrade group display name.
${FROM_VERSION} The current version, or the lowest current member version for an upgrade group.
${TO_VERSION} The planned target version.
${TICKET} The linked ticket reference as shown in the IDE, for example #1234. Empty when no ticket is linked.
${CLOSES} The linked ticket's closing reference rendered from the ticket system's template, for example Closes #1234 on GitHub. Empty when no ticket is linked.
