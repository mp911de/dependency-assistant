This built-in template renders the GitHub issue reference that Dependency Assistant places into commit messages through the ${CLOSES} variable of the Commit Message template.

This built-in template is editable. Along with plain text and Velocity directives, you can also use the predefined variables listed below. They are expanded into the corresponding values. GitHub links and closes issues for the keywords listed in Linking a pull request to an issue. Examples: Fixes ${REFERENCE}, Resolves ${FULL_REFERENCE}, [resolves GH-${NUMBER}].

${NUMBER} The issue number, for example 1234.
${OWNER} The repository owner, for example mp911de.
${REPOSITORY} The repository name, for example dependency-assistant.
${REFERENCE} The short issue reference, for example #1234.
${FULL_REFERENCE} The repository-qualified issue reference, for example github-linguist/linguist#1234.
